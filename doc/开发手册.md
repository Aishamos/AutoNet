# NetAuto 开发手册

本文档为开发者提供项目架构说明、代码规范和扩展指南。

---

## 1. 项目架构

### 1.1 整体架构

```
┌─────────────────────────────────────────────────────────┐
│                    前端展示层                             │
│         Bootstrap 5 + JavaScript + SocketIO             │
└─────────────────────────┬───────────────────────────────┘
                          │ HTTP / WebSocket
┌─────────────────────────┴───────────────────────────────┐
│                    API 接口层                             │
│            Flask Blueprint (8 个 API 模块)               │
├─────────────────────────────────────────────────────────┤
│                    业务逻辑层                             │
│        Python 脚本 (设备连接/Playbook 调度/数据处理)      │
├─────────────────────────────────────────────────────────┤
│                    设备通信层                             │
│            Ansible Playbook + SSH (Netmiko)              │
├─────────────────────────────────────────────────────────┤
│                    数据存储层                             │
│       文件系统 (inventory/backups/logs/reports)          │
└─────────────────────────────────────────────────────────┘
```

### 1.2 请求流程

```
用户操作 → 浏览器 JS → fetch API → Flask 路由 → Python 业务逻辑
    ↓                                              ↓
页面更新 ← JSON 响应 ← API 返回 ← 数据处理 ← Ansible/Netmiko
```

## 3. 核心模块说明

### 3.1 Flask 主入口 (web/app.py)

负责应用初始化、蓝图注册、路由定义。

```python
# 蓝图注册
app.register_blueprint(inventory_bp)   # 设备管理
app.register_blueprint(backup_bp)      # 配置备份
app.register_blueprint(deploy_bp)      # 配置下发
app.register_blueprint(check_bp)       # 校验回滚
app.register_blueprint(report_bp)      # 监控报告
app.register_blueprint(logs_bp)        # 日志管理
app.register_blueprint(status_bp)      # 状态监控
app.register_blueprint(drift_bp)       # 漂移历史

# SocketIO 初始化（实时推送）
socketio = SocketIO(app, cors_allowed_origins="*", async_mode='eventlet')
```

### 3.2 API 蓝图模块

每个 API 模块使用 Flask Blueprint 组织，职责单一：

| 模块 | 文件 | 路由前缀 | 功能 |
|------|------|---------|------|
| 设备管理 | api_inventory.py | /api/devices | 增删改查、连通性验证 |
| 配置备份 | api_backup.py | /api/backup | 备份执行、定时任务、下载 |
| 配置下发 | api_deploy.py | /api/deploy | 模板选择、批量下发 |
| 校验回滚 | api_check_rollback.py | /api/check | 漂移检测、回滚执行 |
| 监控报告 | api_report.py | /api/reports | 报告生成、列表、下载 |
| 日志管理 | api_logs.py | /api/logs | 日志记录与查询 |
| 状态监控 | api_status.py | /api/status | 设备在线状态、实时推送 |
| 漂移历史 | api_drift_history.py | /api/drift | 漂移记录持久化 |

### 3.4 Ansible Playbook

备份 Playbook (playbooks/backup_config.yml)：

```yaml
- name: 华为设备配置备份
  hosts: "{{ target_hosts | default('all') }}"
  gather_facts: false
  strategy: free

  tasks:
    - name: 获取当前配置
      ansible.netcommon.cli_command:
        command: "display current-configuration"
      register: config_output

    - name: 保存配置到本地
      copy:
        content: "{{ config_output.stdout }}"
        dest: "./backups/{{ inventory_hostname }}_{{ timestamp }}.cfg"
      delegate_to: localhost
```

## 4. 前端架构

### 4.1 页面结构

| 页面 | 文件 | 功能 |
|------|------|------|
| 登录 | login.html | 用户认证 |
| 主控台 | dashboard.html | 概览统计 |
| 设备管理 | inventory.html | 设备 CRUD |
| 配置备份 | backup.html | 备份管理 |
| 配置下发 | deploy.html | 批量下发 |
| 校验回滚 | rollback.html | 漂移检测/回滚 |
| 监控报告 | report.html | 报告管理 |

### 4.2 模板继承

所有页面使用 Jinja2 模板继承，共享 `base.html` 中的侧边栏、导航栏、公共 CSS 和 JS：

```html
{% extends "base.html" %}
{% block title %}NetAuto - 页面标题{% endblock %}
{% block style_extra %}/* 页面专属样式 */{% endblock %}
{% block content %}/* 页面内容 */{% endblock %}
{% block script_extra %}/* 页面专属 JS */{% endblock %}
```

`base.html` 提供：
- 权限检查 JS + logout 函数
- 侧边栏抽屉式导航（含高亮逻辑）
- 顶部 header
- 公共 CSS 变量和样式类（`.card`, `.btn-primary`, `.sticky-header` 等）
- `logAction()`, `updateDeviceStatusUI()`, `formatTime()` 通用函数

### 4.3 实时状态刷新

使用 SocketIO 实现设备状态实时推送：

```javascript
// 前端监听
const socket = io();
socket.on('device_status', function(data) {
    // 更新设备状态显示
});

// 后端推送（api_status.py）
socketio.emit('device_status', status_data)
```

## 6. 开发规范

### 6.1 Python 代码规范

- 遵循 PEP 8 规范
- 函数使用 snake_case 命名
- 类使用 CamelCase 命名
- 常量使用 UPPER_CASE 命名
- 关键函数添加 docstring

### 6.2 API 设计规范

- RESTful 风格
- 统一响应格式：

```json
{
    "status": "success|error",
    "message": "操作结果描述",
    "data": {}
}
```

- HTTP 状态码：
  - 200: 成功
  - 400: 请求参数错误
  - 404: 资源不存在
  - 500: 服务器内部错误

### 6.3 前端代码规范

- HTML 使用 Bootstrap 5 组件
- JavaScript 使用原生 ES6+
- 异步请求使用 fetch API
- 样式优先使用 Bootstrap 类，自定义样式写在 `<style>` 中

### 6.4 文件命名

- Python 文件：snake_case.py
- HTML 文件：lowercase.html
- Jinja2 模板：lowercase.j2
- Playbook：lowercase.yml

## 7. 扩展指南

### 7.1 添加新的 API 模块

1. 创建 `web/api_xxx.py`：

```python
from flask import Blueprint, jsonify, request

xxx_bp = Blueprint('xxx_api', __name__)

@xxx_bp.route('/api/xxx', methods=['GET'])
def get_xxx():
    return jsonify({"status": "success", "data": {}})
```

2. 在 `web/app.py` 注册：

```python
from api_xxx import xxx_bp
app.register_blueprint(xxx_bp)
```

### 7.2 添加新的配置模板

1. 在 `templates/` 目录创建 `.j2` 文件：

```jinja
{# 模板说明 #}
{% if variable is defined %}
配置命令 {{ variable }}
{% endif %}
```

2. 在 `web/templates/deploy.html` 添加模板选项

### 7.3 添加新的 Playbook

1. 在 `playbooks/` 目录创建 `.yml` 文件
2. 在对应的 `scripts/` 脚本中调用：

```python
subprocess.run(["ansible-playbook", "playbooks/xxx.yml", "-i", "inventory.yml"])
```

### 7.4 添加新的 HTML 页面

1. 创建 `web/templates/xxx.html`，继承 `base.html`：

```html
{% extends "base.html" %}
{% block title %}NetAuto - 新页面{% endblock %}
{% block content %}<!-- 页面内容 -->{% endblock %}
{% block script_extra %}<!-- 页面 JS -->{% endblock %}
```

2. 在 `web/app.py` 添加路由：

```python
@app.route('/xxx')
def xxx():
    return render_template('xxx.html')
```

3. 在 `base.html` 侧边栏添加导航链接

### 7.5 支持新厂商设备

1. 修改 `ansible.cfg` 中的网络 OS 配置
2. 修改 `inventory.yml` 中的 `ansible_network_os`
3. 调整 `scripts/generate_report.py` 中的正则表达式
4. 测试命令输出格式是否匹配

## 9. 常见问题

### Q: 导入模块报错

A: 确保在 `web/` 目录下运行 `python app.py`，或检查 Python 路径配置。

### Q: Ansible 执行超时

A: 检查 `ansible.cfg` 中的 `timeout` 设置，以及网络连通性。

### Q: 前端页面空白

A: 检查浏览器控制台是否有 JS 错误，以及 CDN 资源是否加载成功。

### Q: 设备命令无响应

A: 华为设备可能需要特定的命令格式，检查 `ansible_network_os` 配置。
